# 💻 Portfólio | Fellipe Kock

Meu site pessoal, onde apresento quem sou, o que sei e como falar comigo. Feito do zero com **HTML, CSS e JavaScript puro**, sem frameworks.

🔗 **Acesse:** [fellipekock-dev.github.io/portifolio](https://fellipekock-dev.github.io/portifolio/)

## ✨ O que tem no site

- Tema escuro com destaques em vermelho, azul royal e roxo
- Layout responsivo, para celular, tablet e computador
- Texto animado na apresentação, com efeito de digitação
- Menu que destaca a seção atual e animações ao rolar a página
- Seções: **Sobre**, **Habilidades**, **Projetos**, **Trajetória** e **Contato**
- Respeita a preferência de movimento reduzido do sistema

## 🚀 Como rodar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/fellipekock-dev/portifolio.git
   ```
2. Entre na pasta:
   ```bash
   cd portifolio
   ```
3. Abra o `index.html` no navegador.

Não precisa instalar nada. As fontes são carregadas do Google Fonts, então é preciso estar conectado à internet.
